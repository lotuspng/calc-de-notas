Este programa permite registrar estudiantes, introducir sus cuatro calificaciones y calcular sus promedios. También indica si están aprobados o reprobados y muestra un resumen de los resultados del grupo.
Datos de entrada
Cantidad de estudiantes.
Nombre de cada estudiante.
Cuatro calificaciones por estudiante.
Proceso
El programa suma las cuatro calificaciones y divide el resultado entre cuatro para obtener el promedio individual. Después cuenta los aprobados y reprobados, calcula el promedio general e identifica al estudiante con el promedio más alto.
Datos de salida
Promedio de cada estudiante.
Estado de aprobación.
Cantidad de aprobados y reprobados.
Promedio general del grupo.
Estudiante con el mejor promedio.
